# برنامه آموزشی BOOTCRAFT

> **طرح پیشنهادی:** دو کارگاه اصلی در دو روز جداگانه، به‌علاوه یک کلینیک پیشرفته اختیاری.  
> **سطح:** مقدماتی تا متوسط؛ بدون نیاز به تجربه قبلی نصب لینوکس.  
> **مدت مسیر اصلی:** ۷ ساعت و ۳۰ دقیقه آموزش/تمرین، بدون احتساب استراحت‌های بلند.

## ۱. خروجی‌های یادگیری

در پایان دو کارگاه اصلی، دانشجو باید بتواند:

1. زنجیره راه‌اندازی از روشن‌شدن دستگاه تا اجرای محیط کاربر را با واژگان درست توضیح دهد.
2. تفاوت UEFI و BIOS قدیمی، GPT و MBR و نقش ESP را تشخیص دهد.
3. ساختار کلی دیسک ویندوز و لینوکس و کاربرد فایل‌سیستم‌های رایج را بخواند.
4. رسانه نصب را از Image معتبر ایجاد و منبع آن را بررسی کند.
5. محیط Live لینوکس را اجرا کند و بدون نوشتن روی دیسک، سخت‌افزار و ذخیره‌ساز را شناسایی کند.
6. نقش Windows Boot Manager و GRUB را در مسیر بوت شرح دهد.
7. نصب تحت نظارت را روی دستگاه آزمایشگاهی دانشگاه یا دیسک مجازی انجام دهد.
8. برای خطای بوت، اولین فرضیه و ابزار بررسی مناسب را انتخاب کند.

## ۲. پیش‌نیازها

- آشنایی عمومی با فایل‌ها، پوشه‌ها و کار با رایانه
- توانایی استفاده از ماوس و صفحه‌کلید
- کنجکاوی و آمادگی برای کار گروهی

آشنایی با ترمینال، پارتیشن‌بندی یا لینوکس الزامی نیست. این مفاهیم در طول برنامه معرفی می‌شوند.

## ۳. کارگاه اول — زیر پوست سیستم

**مدت پیشنهادی: ۳ ساعت و ۳۰ دقیقه**

| زمان | بخش | محتوای کلیدی | روش |
|---|---|---|---|
| ۰۰:۰۰–۰۰:۱۵ | شروع و سنجش | آزمون تشخیصی، هدف‌ها و قواعد ایمنی | تعاملی |
| ۰۰:۱۵–۰۰:۵۵ | Firmware | POST، UEFI/BIOS، Boot Order، NVRAM، Secure Boot، TPM و ACPI | ارائه + نمایش |
| ۰۰:۵۵–۰۱:۳۰ | زبان دیسک | GPT/MBR، ESP، MSR، Recovery، Swap، root و home | دیاگرام + تمرین |
| ۰۱:۳۰–۰۱:۴۰ | استراحت | — | — |
| ۰۱:۴۰–۰۲:۲۰ | فایل‌سیستم‌ها | FAT32، NTFS، ext4، Btrfs؛ تفاوت پارتیشن و فایل‌سیستم | نمایش |
| ۰۲:۲۰–۰۳:۰۰ | رسانه نصب | ISO، USB boot، UEFI boot و Live Session | نمایش هدایت‌شده |
| ۰۳:۰۰–۰۳:۳۰ | ایستگاه نقشه‌خوانی | تحلیل طرح دیسک نمونه و ثبت نتیجه | کار گروهی |

**تمرین قابل ارزیابی:** هر گروه یک طرح دیسک نمونه دریافت می‌کند و نوع جدول پارتیشن، ESP، پارتیشن سیستم و Recovery را مشخص می‌کند. در این ایستگاه هیچ پارتیشن واقعی حذف یا فرمت نمی‌شود.

## ۴. کارگاه دوم — نصب، بوت، انتخاب

**مدت پیشنهادی: ۴ ساعت**

| زمان | بخش | محتوای کلیدی | روش |
|---|---|---|---|
| ۰۰:۰۰–۰۰:۱۵ | مرور و کنترل ایمنی | مالکیت دستگاه، بکاپ، رمزگذاری، دیسک هدف | چک‌لیست |
| ۰۰:۱۵–۰۰:۴۵ | آماده‌سازی | بررسی Image، ساخت USB و انتخاب Boot Device | نمایش + تمرین |
| ۰۰:۴۵–۰۱:۲۰ | Live Linux | شناسایی سخت‌افزار، دیسک و شبکه؛ بدون تغییر ذخیره‌ساز | عملی |
| ۰۱:۲۰–۰۱:۳۰ | استراحت | — | — |
| ۰۱:۳۰–۰۲:۴۵ | نصب کنترل‌شده | نصب روی VM یا SSD آزمایشگاهی اختصاصی | عملی با نظارت |
| ۰۲:۴۵–۰۳:۲۰ | Boot Manager | Windows Boot Manager، GRUB، Boot Order و مفهوم Dual Boot | نمایش |
| ۰۳:۲۰–۰۴:۰۰ | اعتبارسنجی | بوت موفق، بررسی پارتیشن‌ها و گزارش گروه | عملی + پس‌آزمون |

نصب Windows 11 باید روی سخت‌افزار سازگار و مطابق الزامات رسمی پشتیبانی‌شده انجام شود. دور زدن TPM، Secure Boot یا سایر الزامات برای این کارگاه پیشنهاد یا آموزش داده نمی‌شود. برای آموزش مفاهیم قدیمی یا دستگاه ناسازگار، از VM یا سناریوی شبیه‌سازی‌شده استفاده شود.

## ۵. کارگاه سوم — کلینیک نجات

**اختیاری / سطح پیشرفته / ۳ ساعت**

| زمان | بخش | تمرین |
|---|---|---|
| ۰۰:۰۰–۰۰:۲۰ | مدل عیب‌یابی | تفکیک خطای Firmware، Bootloader، Kernel و فایل‌سیستم |
| ۰۰:۲۰–۰۱:۰۰ | Windows Recovery | آشنایی با WinRE و گزینه‌های Startup Repair و Restore |
| ۰۱:۰۰–۰۱:۱۰ | استراحت | — |
| ۰۱:۱۰–۰۲:۰۰ | Linux recovery | بررسی Boot Order، ورودی EFI و سناریوهای GRUB در VM |
| ۰۲:۰۰–۰۲:۴۰ | Backup & Restore | انتخاب نسخه پشتیبان، بازیابی و اعتبارسنجی |
| ۰۲:۴۰–۰۳:۰۰ | Incident report | ثبت مشاهدات، فرضیه، اقدام و نتیجه |

این کلینیک آموزش تخصصی بازیابی داده یا تعمیر Firmware نیست. سناریوها باید ساختگی، قابل‌بازگشت و محدود به محیط آزمایشگاهی باشند.

## ۶. طراحی ایستگاه‌ها

### ایستگاه A — نقشه‌خوانی دیسک
- ورودی: تصویر یا VM دارای دیسک نمونه
- وظیفه: تشخیص GPT/MBR، ESP، پارتیشن سیستم و Recovery
- خروجی: دیاگرام برچسب‌گذاری‌شده
- ممنوع: حذف، فرمت یا تغییر جدول پارتیشن

### ایستگاه B — ردیابی بوت
- ورودی: Firmware قابل مشاهده یا VM
- وظیفه: مشاهده Boot Order، Secure Boot و ورودی بوت
- خروجی: نمودار مسیر بوت
- ممنوع: تغییر تنظیمات ناشناخته یا Firmware update

### ایستگاه C — نصب کنترل‌شده
- ورودی: دستگاه دانشگاهی آماده‌سازی‌شده یا دیسک مجازی Disposable
- وظیفه: نصب و اعتبارسنجی سیستم‌عامل
- خروجی: اسکرین‌شات/گزارش ساختار دیسک و وضعیت بوت
- شرط شروع: تأیید دو نفره دیسک هدف و وجود مسیر Rollback

### ایستگاه D — کارآگاه خطای بوت
- ورودی: Snapshot معیوب یا سناریوی شبیه‌سازی‌شده
- وظیفه: طبقه‌بندی خطا و انتخاب ابزار تشخیص
- خروجی: Incident report کوتاه
- ممنوع: دست‌کاری دستگاه واقعی خارج از محیط قربانی‌پذیر

## ۷. تیم اجرایی و ظرفیت

برای یک نوبت ۱۲ تا ۱۶ نفره:

- ۱ مدرس اصلی
- ۱ دستیار فنی
- ۱ مسئول تجهیزات و ایمنی (می‌تواند نقش مشترک داشته باشد، اما مسئولیت باید روشن باشد)
- ۴ تا ۸ دستگاه آزمایشگاهی، بر اساس گروه‌های ۲ تا ۳ نفره
- حداقل یک مسیر جایگزین VM برای هر ایستگاه حساس

## ۸. سنجش یادگیری

| ابزار سنجش | وزن پیشنهادی | معیار |
|---|---:|---|
| آزمون تشخیصی و پس‌آزمون | ۲۰٪ | فهم مفاهیم پایه |
| چک‌لیست مهارت ایستگاهی | ۴۰٪ | اجرای درست و ایمن |
| گزارش گروه | ۲۵٪ | توضیح تصمیم‌ها و شواهد |
| مشارکت و نظم ایمنی | ۱۵٪ | رعایت مراحل و همکاری |

## ۹. معیار موفقیت دوره

- حداقل ۸۰٪ شرکت‌کنندگان بتوانند مسیر بوت را با ترتیب درست توضیح دهند.
- حداقل ۸۰٪ گروه‌ها ESP و نوع جدول پارتیشن را درست تشخیص دهند.
- همه عملیات نوشتن روی دیسک دارای تأیید هدف و چک‌لیست ثبت‌شده باشد.
- هیچ دستگاه شخصی در معرض عملیات نصب یا پارتیشن‌بندی قرار نگیرد.
- برای تمام دستگاه‌های آزمایشگاهی، فرآیند بازگردانی وضعیت پایه ثبت شده باشد.

این اعداد هدف طراحی هستند، نه نتایج اندازه‌گیری‌شده. پس از اجرای نخست، باید با داده واقعی بازنگری شوند.
