# منابع فنی و مطالعه تکمیلی

این فهرست برای تهیه محتوای آموزشی است. در نسخه نهایی هر برگه تمرین، نسخه/تاریخ سند و بخش مورد استناد ثبت شود. اولویت با مستندات رسمی و منابع اولیه است.

## Windows

- [Windows 11 specifications and system requirements](https://www.microsoft.com/windows/windows-11-specifications) — الزامات سخت‌افزاری رسمی.
- [Windows 11 installation media](https://www.microsoft.com/software-download/windows11) — دریافت رسانه نصب رسمی.
- [Windows Recovery options](https://support.microsoft.com/windows) — راهنمای پشتیبانی و بازیابی.
- [BitLocker overview](https://learn.microsoft.com/windows/security/operating-system-security/data-protection/bitlocker/) — رمزگذاری دستگاه و مدیریت کلید بازیابی.
- [Windows installation documentation](https://learn.microsoft.com/windows-hardware/manufacture/desktop/) — مستندات نصب و استقرار.

## Firmware and boot

- [UEFI Forum — Specifications](https://uefi.org/specifications) — مرجع مشخصات UEFI.
- [UEFI Forum — Resources](https://uefi.org/) — منابع و اسناد فنی UEFI.
- [Microsoft Secure Boot](https://learn.microsoft.com/windows-hardware/design/device-experiences/oem-secure-boot) — مفاهیم Secure Boot در اکوسیستم Windows.
- [Trusted Computing Group](https://trustedcomputinggroup.org/) — منابع TPM و ریشه اعتماد سخت‌افزاری.

## Linux installation and boot

- [Ubuntu Desktop installation tutorial](https://ubuntu.com/tutorials/install-ubuntu-desktop) — نصب Ubuntu.
- [Ubuntu documentation](https://documentation.ubuntu.com/) — مستندات رسمی.
- [Fedora Documentation](https://docs.fedoraproject.org/) — مستندات نصب و مدیریت Fedora.
- [GNU GRUB Manual](https://www.gnu.org/software/grub/manual/) — مستندات رسمی GRUB.
- [systemd-boot manual](https://www.freedesktop.org/software/systemd/man/latest/systemd-boot.html) — مرجع systemd-boot.

## Storage and filesystems

- [Linux kernel documentation](https://docs.kernel.org/) — مستندات هسته لینوکس.
- [util-linux documentation](https://github.com/util-linux/util-linux) — ابزارهای مدیریت دیسک و سیستم.
- [The Linux man-pages project](https://www.kernel.org/doc/man-pages/) — مرجع ابزارهای خط فرمان و رابط‌های سیستم.
- [The Open Group — POSIX](https://pubs.opengroup.org/onlinepubs/9699919799/) — استانداردهای رابط سیستم‌عامل.

## Teaching and lab design

- [NIST NICE Framework](https://www.nist.gov/itl/applied-cybersecurity/nice/nice-framework-resource-center) — چارچوب مهارت‌ها؛ فقط برای الهام در طراحی سنجش و نقش‌ها.
- [GitHub Pages documentation](https://docs.github.com/pages) — مستندات رسمی استقرار وب‌سایت.
- [GitHub Actions documentation](https://docs.github.com/actions) — مستندات CI و انتشار خودکار.

## Editorial rules

1. برای مشخصات Windows، Firmware یا ابزارها از اسناد رسمی نسخه جاری استفاده شود.
2. الزامات و رفتارهای نسخه‌ای را به‌عنوان حقیقت همیشگی ننویسید.
3. هر دستور مخرب یا تغییردهنده دیسک باید در محیط Disposable تست شده و هشدار روشن داشته باشد.
4. راهکارهای دور زدن الزامات نصب Windows 11 وارد دستورکار کارگاه نشود.
5. تاریخ آخرین بازبینی و نسخه سیستم‌عامل هدف روی هر برگه تمرین نوشته شود.
