# واژه‌نامه دوزبانه — Glossary

هر واژه یک تعریف کوتاه و یک «چرا مهم است». هدف این است که دانشجو در جلسه بتواند
با واژه درست حرف بزند، نه اینکه اصطلاح حفظ کند.

| فارسی | English | تعریف | چرا مهم است |
|---|---|---|---|
| فریم‌ور | Firmware | نرم‌افزار ثابت روی مادربورد که سخت‌افزار را راه می‌اندازد | اولین چیزی که پس از پاور اجرا می‌شود؛ تنظیمات بوت اینجاست |
| POST | Power-On Self-Test | آزمون خودکار سخت‌افزار در شروع | خطای POST پیش از هر سیستم‌عاملی رخ می‌دهد |
| UEFI | Unified Extensible Firmware Interface | استاندارد مدرن فریم‌ور، جانشین BIOS | شرط Secure Boot، GPT و بوت سریع |
| BIOS (legacy) | Basic Input/Output System | فریم‌ور قدیمی با محدودیت‌های سخت‌افزاری | تشخیص آن برای فهم دستگاه‌های قدیمی لازم است |
| NVRAM | Non-Volatile RAM | حافظه پایدار فریم‌ور برای ورودی‌های بوت | ترتیب بوت و متغیرهای بوت اینجا ذخیره می‌شوند |
| ترتیب بوت | Boot order | فهرست ترتیبی دستگاه‌هایی که فریم‌ور امتحان می‌کند | رایج‌ترین علت «بوت نمی‌شود» |
| Secure Boot | Secure Boot | زنجیره امضای دیجیتال برای اجرای فقط بوت‌لودرهای تأییدشده | مانع بوت رسانه‌های ناشناس می‌شود |
| TPM | Trusted Platform Module | تراشه ذخیره کلید و اندازه‌گیری وضعیت سیستم | پایه BitLocker و attestation |
| جدول پارتیشن | Partition table | نقشه پارتیشن‌های یک دیسک | GPT یا MBR بودن، کل مسیر بوت را تعیین می‌کند |
| GPT | GUID Partition Table | جدول پارتیشن مدرن با شناسه یکتا | پیش‌نیاز بوت UEFI روی دیسک بزرگ |
| MBR | Master Boot Record | جدول پارتیشن قدیمی با محدودیت ۲ ترابایت و ۴ پارتیشن اصلی | هنوز روی دستگاه‌های قدیمی دیده می‌شود |
| پارتیشن | Partition | بخشی از دیسک با مرز مشخص | واحد پایه چیدمان دیسک |
| فایل‌سیستم | Filesystem | ساختار سازمان‌دهی فایل‌ها روی یک پارتیشن | تفاوت آن با پارتیشن، خطای رایج مبتدی است |
| ESP | EFI System Partition | پارتیشن کوچک FAT32 برای بوت‌لودرهای UEFI | بدون ESP سالم، UEFI بوت نمی‌شود |
| MSR | Microsoft Reserved | پارتیشن رزروشده ویندوز | حذف آن می‌تواند مدیریت دیسک ویندوز را بشکند |
| پارتیشن بازیابی | Recovery partition | محیط بازیابی سازنده یا ویندوز | ابزار اول نجات، پیش از هر تغییر |
| Swap | Swap | فضای دیسک به‌عنوان حافظه کمکی | روی SSD رفتار و اندازه‌اش مهم است |
| root / home | root / home | پارتیشن سیستم و پارتیشن داده کاربر | جداکردنشان، نصب دوباره را کم‌دردسر می‌کند |
| بوت‌لودر | Bootloader | برنامه‌ای که کرنل را بارگذاری می‌کند | GRUB و Windows Boot Manager دو نمونه اصلی |
| GRUB | GRUB | بوت‌لودر رایج لینوکس | نقطه اصلی بازیابی بوت لینوکس |
| Windows Boot Manager | Windows Boot Manager | بوت‌لودر ویندوز | در Dual Boot باید هر دو شناخته شوند |
| Dual Boot | Dual Boot | نصب دو سیستم روی یک دستگاه | نیازمند برنامه‌ریزی پارتیشن و ترتیب بوت |
| کرنل | Kernel | هسته سیستم‌عامل | مرز بین سخت‌افزار و نرم‌افزار کاربر |
| محیط کاربر | Userspace | برنامه‌های کاربر پس از بوت کرنل | آخرین مرحله زنجیره بوت |
| Live | Live environment | اجرای سیستم از رسانه بدون نصب | محیط امن برای بررسی پیش از تغییر |
| ISO | Disk image | تصویر کامل یک رسانه | باید از منبع رسمی و با checksum تأیید شود |
| checksum | Checksum | اثر انگشت عددی فایل | تنها راه ساده اطمینان از سالم‌بودن ISO |
| رسانه بوت | Boot media | USB یا دیسک قابل بوت | کیفیت و سلامت آن، نصف موفقیت نصب است |
| WinRE | Windows Recovery Environment | محیط بازیابی ویندوز | ابزار اول برای بوت خراب ویندوز |
| BitLocker | BitLocker | رمزگذاری دیسک ویندوز | کلید بازیابی باید جدا و تست‌شده باشد |
| virtualization | مجازی‌سازی | اجرای سیستم داخل سیستم | محیط امن برای تمرین نصب |
| Hypervisor | Hypervisor | نرم‌افزار مدیریت ماشین مجازی | تفاوت Type 1 و Type 2 را بدانید |
| snapshot | Snapshot | تصویر لحظه‌ای از وضعیت VM | بازگشت‌پذیری تمرین را ممکن می‌کند |
| backup 3-2-1 | 3-2-1 backup | سه نسخه، دو رسانه، یک نسخه خارج از محل | بکاپی که تست بازیابی نشده، بکاپ نیست |
